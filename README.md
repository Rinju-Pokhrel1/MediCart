
# 💊 MediCart

### Pharmacy E-Commerce System with Dynamic Pricing

MediCart is a web-based pharmacy e-commerce platform that makes browsing and purchasing healthcare products easier through dynamic pricing, shopping cart management, and secure user authentication.

## ✨ Key Features

- Browse and search medicines and healthcare products.
- Product categories and dynamic pricing.
- Shopping cart and quantity management.
- User registration and login.
- Order and checkout management.
- Admin dashboard for product and inventory management.
- Dummy payment gateway.
- Product recommendations.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** SQLite
- **Connectivity:** PDO

## 🚀 Getting Started

### Prerequisites
- PHP 8.0+
- SQLite support enabled in PHP
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rinju-Pokhrel1/MediCart.git
   ```

2. Navigate to the project:

   ```bash
   cd MediCart
   ```

3. Start the PHP development server:

   ```bash
   php -S localhost:8000
   ```

4. Open in your browser:

   ```text
   http://localhost:8000
   ```
